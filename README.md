# Nardaram: Los Nuevos Bosques

RPG + gestión de ciudad, indie, pixel art 8-bit. PC → Steam.

- Motor: Godot 4.x (GDScript). Stack completo en `docs/STACK.md`.
- Visión del juego: `docs/design/GDD.md`.
- Trabajo por agentes: `CLAUDE.md` decide qué agente aplica; cada agente está en `.claude/agents/`.

## Abrir el proyecto
1. Instalar Godot 4.5+ (standard, no .NET): `winget install GodotEngine.GodotEngine`.
2. Correr `tools/test.sh` (Git Bash). Instala GUT y corre los tests.
3. Abrir `project.godot` y ejecutar (F5). Debe verse la pantalla base a 320×180 escalada.

## Requisitos de herramientas
- Aseprite (arte), FamiStudio (música), Git LFS.
